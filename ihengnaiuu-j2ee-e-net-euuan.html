    5. 日程安排服务 J2EE 的 .NET 客户端

    5.1. 一个 C# 2008 客户端

    我们现在假设前面的 Web 服务已可用且处于活动状态。Web 服务可供使用不同语言编写的客户端使用。在此，我们将编写一个 C# 控制台客户端来显示医生列表。

    首先创建 C# 项目：

    创建一个名为 [1] 的控制台应用程序 [ListeDesMedecins] [2]。 在 [3] 中，我们为一个 Web 服务创建引用。该工具与 NetBeans 中使用的类似：它会为远程 Web 服务创建一个本地代理。

    • 在 [1] 中，需指定 Web 服务的 WSDL 文件的 URI（参见第 4.10.2 节）。
    • 在 [2] 中，要求向导发现该 URI 所暴露的 Web 服务
    • 在 [3] 中，列出已找到的 Web 服务；在 [4] 中，列出该服务暴露的方法。
    • 在 [5] 中，指定代理 C 的类应在哪个命名空间中生成
    • 在 [6] 中，生成 C 语言代理。
    • 在 [1] 中，显示了我们刚刚创建的 Web 引用。双击它。
    • 在 [2] 中，双击打开的对象浏览器。
    • 在 [3] 中，选择命名空间 [ListeDesMedecins.Ws.RdvMedecins]，即生成的 C 代理的命名空间。 第一个项 [ListeDesMedecins] 是所创建的 C# 应用程序的默认命名空间（我们将其命名为 ListeDesMedecins）。 第二个名称 [Ws.Rdvmedecins] 是我们在向导中为 C 代理指定的命名空间。最终，C 代理的对象属于命名空间 [ListeDesMedecins.Ws.RdvMedecins]。
    • 在 [4] 中，生成的 C 代理对象
    • 在 [5] 中，[WsDaoJpaClient] 是本地实现远程 Web 服务方法的类。
    • 在 [6] 中，包含类 [WsDaoJpaClient] 的方法。其中包含远程 Web 服务的方法，例如 getAllClients 对应 [7]。

    值得注意的是，生成的代码未遵循 C# 的常规编码规范。类名和公共属性的名称应以大写字母开头。

    让我们回到我们的 C# 应用程序：

    [Program.cs][1] 是测试类。其代码如下：

    
using System;
using ListeDesMedecins.Ws.RdvMedecins;
using Client = ListeDesMedecins.Ws.RdvMedecins.client;

namespace ListeDesMedecins {
    class Program {
        static void Main(string[] args) {
            try {
                // 客户端 [dao] 层的实例化
                WsDaoJpaClient dao = new WsDaoJpaClient();
                // 医生列表
                foreach (Client client in dao.getAllClients()) {
                    Console.WriteLine(String.Format("{0} {1} {2}", client.titre, client.prenom, client.nom));
                }
            } catch (Exception e) {
                Console.WriteLine(e);
            }
        }
    }
}

    第 12 行中，使用了 C 语言代理的 [Client] 类，而我们刚才看到它实际上名为 [client]。 正是第 3 行的声明，使我们能够使用 [Client] 代替 [client]。这让我们能够遵守类名的编码规范。 同样在第12行，使用的是方法 [getAllClients]，因为这是它在 C 代理中的名称。根据 C# 命名规范，该方法应命名为 [GetAllClients]。

    与展示页面 [Default.aspx] 关联的控制代码 [Default.aspx.cs] 如下：

    
using System;
using ListeDesClients1.Ws.RdvMedecins;

namespace ListeDesClients1
{
  public partial class _Default : System.Web.UI.Page
  {
    protected void Page_Load(object sender, EventArgs e)
    {
      try
      {
        // 远程层 [dao] 的本地代理实例
        WsDaoJpaService dao = new WsDaoJpaService();
        // 客户端视图
        Vues.ActiveViewIndex = 0;
        // 客户端视图初始化
        RepeaterClients.DataSource = dao.getAllClients();
        RepeaterClients.DataBind();
      }
      catch (Exception ex)
      {
        // 错误视图
        Vues.ActiveViewIndex = 1;
        //错误视图初始化
        LabelErreur.Text = ex.ToString();
      }
    }
  }
}
    • 第 8 行：在页面初始加载时执行方法 Page_Load。每次客户端请求该页面时都会进行此加载。
    • 第 13 行：实例化本地代理 C。该代理 C 实现了远程 Web 服务的接口。应用程序将与该代理 C 进行交互。
    • 第 15 行：若在实例化本地代理 C 时未发生异常，则应显示名为“VueClients”的视图，即 c.a.d。 即页面“视图”中的 MultiView 视图中的第 0 号视图。
    • 第 17 行：répéteur 的数据源是代理 C 的 getAllClients 方法提供的客户列表。
    • 第 23 行：如果在实例化本地代理 C 时发生异常，则应显示名为“VueErreurs”的视图，c.a.d。 页面中 MultiView “视图”下的第 1 个视图。
    • 第25行：异常显示在label“LabelErreur”中。
