    本教程旨在展示如何使用 IDE NetBeans 6.5 及其配套的 GlassFish 应用服务器来创建和部署 J2EE Web 服务。 此外，我们将介绍该 Web 服务的多种客户端：Java、C#、Asp.Net 和 Flex 客户端。

    所使用的工具包括：

    • SGBD MySQL 5 [http://www.mysql.com/]
    • IDE NetBeans 6.5 [http://www.netbeans.org/]
    • IDE Visual Studio Express 2008 SP1 (C# 和 Web) [http://www.microsoft.com/Express/]
    • IDE Adobe Flex Builder 3 [https://www.adobe.com/cfusion/tdrc/index.cfm?loc=fr_fr&product=flex]
    • Wamp 工具中的 Apache 服务器 [http://www.wampserver.com/]
    • Adobe Flash Player：[http://www.adobe.com/fr/products/flashplayer/]

    本教程并未对代码进行逐行详解。因此，本教程适合已具备 NetBeans、Java EE、EJB3 和 JPA 基础经验的读者。 本教程中使用的所有元素均在 [ref1] 和 [ref2] 中进行了说明，但本教程本身未必会详细说明。

    • [5]：服务 JEE 的 Flex 3 客户端
